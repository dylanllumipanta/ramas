📘 Diccionario Git Interactivo

Aprende los comandos esenciales para trabajar con repositorios y ramas

🌱

git init

Inicializa un nuevo repositorio local en la carpeta actual.

📥

git clone

Descarga una copia exacta de un repositorio remoto.

➕

git add

Prepara los cambios (staging) para ser incluidos en el próximo commit.

💾

git commit

Guarda los cambios preparados en el historial del repositorio.

🌿

git branch

Permite crear, listar y administrar ramas del proyecto.

🔀

git merge

Combina los cambios de una rama con otra.
